# VVV 멀티 비디오 플레이어

단일 HTML 파일(`index.html`) 하나로 동작하는 멀티 영상 재생 플레이어입니다. 서버·빌드·외부 라이브러리 없이 브라우저에서 바로 열어 사용합니다.

## 주요 기능

- **1~4개 영상 동시 재생**: 상단의 `1 / 2 / 3 / 4` 버튼으로 화면 분할 레이아웃 전환
  - 1개: 전체 화면, 2개: 상하(가로 모드에선 좌우), 3개: 상단 와이드 + 하단 2분할, 4개: 2×2 그리드
- **nPlayer 스타일 UI**: 다크 테마, 그라데이션 하단 컨트롤 바, 자동 숨김(3초), 드래그 탐색 가능한 진행 바
- **슬롯별 개별 컨트롤**: 재생/일시정지, 음소거, 배속(0.5x~2x), PiP(화면 속 화면), 전체화면, 영상 교체
- **전체 컨트롤**: 전체재생 / 전체정지 / 전체 음소거
- **모바일 최적화**: `playsinline` 인라인 재생, 터치 탐색, 세이프 에어리어(노치) 대응

## 아이폰(파일 앱)에서 사용하기

1. `index.html`을 아이폰의 **파일(Files) 앱**에 저장합니다.
   - AirDrop, iCloud Drive, 메일 첨부, 카카오톡/메신저 다운로드 등 어떤 방법이든 가능
2. 파일 앱에서 `index.html`을 탭하거나, Safari 주소창에 공유하여 엽니다.
   - 파일 앱 미리보기로 열리는 경우: 공유 버튼 → **Safari로 열기**
3. 각 슬롯의 **영상 선택** 버튼을 탭하면 iOS 선택창이 뜨고, **파일 앱(둘러보기)** 또는 사진 보관함에서 영상을 고를 수 있습니다.
4. 선택한 영상은 기기에서 직접 재생되며(로컬 Blob), 어디에도 업로드되지 않습니다.

> 참고: iOS Safari의 자동재생 정책상 소리가 있는 영상은 첫 재생 시 탭이 필요할 수 있습니다. 여러 영상의 소리를 동시에 들으려면 각 슬롯의 음소거를 해제하세요.

## 지원 포맷

브라우저(iOS는 Safari 기준)가 재생 가능한 포맷을 그대로 따릅니다: MP4(H.264/HEVC), MOV, M4V, WebM(데스크톱) 등.
