# VVV 멀티 비디오 플레이어

단일 HTML 파일(`index.html`) 하나로 동작하는 멀티 영상 재생 플레이어입니다. 서버·빌드·외부 라이브러리 없이 브라우저에서 바로 열어 사용합니다.

## 주요 기능

- **1~4개 영상 동시 재생**: 상단의 `1 / 2 / 3 / 4` 버튼으로 화면 분할 레이아웃 전환
  - 1개: 전체 화면, 2개: 상하(가로 모드에선 좌우), 3개: 상단 와이드 + 하단 2분할, 4개: 2×2 그리드
- **nPlayer 스타일 UI**: 다크 테마, 전체 화면을 덮는 비디오 그리드 위에 상단 바·컨트롤 바가 오버레이로 표시됨
- **몰입형 재생**: 영상 재생 중에는 잠시 후 모든 UI(상단 바 + 컨트롤 바)가 자동으로 사라짐. 화면을 **더블 탭**하면 UI가 다시 오버레이로 나타남(레이아웃은 밀리지 않음)
- **화면 꽉 채우기**: 영상 종횡비를 무시하고 각 슬롯 프레임에 꽉 차게 표시
- **파일 또는 URL로 재생**: 기기의 영상 파일을 선택하거나, 직접 재생 가능한 영상 URL(mp4·m3u8 등)을 입력해서 재생
- **슬롯별 개별 컨트롤**: 재생/일시정지, 음소거, 배속(0.5x~2x), PiP(화면 속 화면), 전체화면, 영상 교체
- **전체 컨트롤**: 전체재생 / 전체정지 / 전체 음소거
- **모바일 최적화**: `playsinline` 인라인 재생, 터치 탐색, 세이프 에어리어(노치) 대응

## 아이폰(파일 앱)에서 사용하기

1. `index.html`을 아이폰의 **파일(Files) 앱**에 저장합니다.
   - AirDrop, iCloud Drive, 메일 첨부, 카카오톡/메신저 다운로드 등 어떤 방법이든 가능
2. 파일 앱에서 `index.html`을 탭하거나, Safari 주소창에 공유하여 엽니다.
   - 파일 앱 미리보기로 열리는 경우: 공유 버튼 → **Safari로 열기**
3. 각 슬롯의 **영상 선택** 버튼을 탭하면 iOS 선택창이 뜨고, **파일 앱(둘러보기)** 또는 사진 보관함에서 영상을 고를 수 있습니다.
   - 파일 대신 **주소(URL)로 재생**하려면 빈 슬롯의 "또는 URL로 재생"을, 이미 영상이 있는 슬롯은 우측 상단의 링크 아이콘을 눌러 mp4·m3u8 등 직접 재생 가능한 영상 파일 주소를 입력하세요. 유튜브 등 일반 웹페이지 링크는 지원되지 않습니다.
4. 영상을 불러온 뒤에는 중앙의 재생 버튼을 직접 눌러 재생을 시작하세요. 여러 슬롯을 연속으로 채울 때도 각 슬롯을 탭해서 재생하면 iOS의 자동재생 제스처 제한 없이 모두 안정적으로 재생됩니다.
5. 파일로 불러온 영상은 기기에서 직접 재생되며(로컬 Blob) 어디에도 업로드되지 않습니다. URL로 불러온 영상은 해당 URL 서버로 직접 스트리밍 요청이 나갑니다(이 앱을 거치지 않는 일반적인 `<video>` 재생과 동일).

> **동시 재생과 소리에 대해**: iOS/Safari는 소리가 있는 영상을 여러 개 동시에 재생하는 것을 지원하지 않아, 새 영상을 재생하면 이전에 재생 중이던(음소거 안 된) 영상이 자동으로 일시정지됩니다. 이를 피하기 위해 모든 영상은 기본적으로 **음소거 상태로 로드**됩니다 — 화면(그림)은 여러 개가 동시에 재생되고, 소리가 필요한 슬롯만 해당 슬롯의 음소거 버튼으로 개별 해제해서 사용하세요.
>
> 참고: 동시 재생 가능한 영상 개수는 기기의 하드웨어 비디오 디코더 성능에도 영향을 받습니다. 구형 기기에서 3~4개 고화질 영상을 동시에 재생하면 버벅일 수 있습니다.

## 지원 포맷

브라우저(iOS는 Safari 기준)가 재생 가능한 포맷을 그대로 따릅니다: MP4(H.264/HEVC), MOV, M4V, WebM(데스크톱) 등.
