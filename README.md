# VVV 멀티 비디오 플레이어

단일 HTML 파일(`index.html`) 하나로 동작하는 멀티 영상 재생 플레이어입니다. 서버·빌드·외부 라이브러리 없이 브라우저에서 바로 열어 사용합니다.

## 주요 기능

- **1~4개 영상 동시 재생**: 상단의 `1 / 2 / 3 / 4` 버튼으로 화면 분할 레이아웃 전환
  - 1개: 전체 화면, 2개: 상하(가로 모드에선 좌우), 3개: 상단 와이드 + 하단 2분할, 4개: 2×2 그리드
- **nPlayer 스타일 UI**: 다크 테마, 전체 화면을 덮는 비디오 그리드 위에 상단 바·컨트롤 바가 오버레이로 표시됨
- **몰입형 재생**: 영상 재생 중에는 잠시 후 모든 UI(상단 바 + 컨트롤 바)가 자동으로 사라짐. 화면을 **더블 탭**하면 UI가 다시 오버레이로 나타남(레이아웃은 밀리지 않음)
- **화면 채우기 방식 선택**: 상단 버튼으로 **화면 꽉 차게 늘리기**(기본값, 종횡비 무시하고 슬롯 프레임에 꽉 채움)와 **원본 비율 유지**(레터박스, 잘리거나 늘어나지 않고 영상 본래 비율대로 표시) 중 전체 슬롯에 적용할 방식을 전환
- **파일 또는 URL로 재생**: 기기의 영상 파일을 선택하거나, 직접 재생 가능한 영상 URL(mp4·m3u8 등)을 입력해서 재생. 교체(🔁)·URL(🔗) 버튼은 재생 중에도 항상 눌러 다른 영상으로 바로 바꿀 수 있음(몰입 모드로 다른 UI가 숨어 있어도 유지됨)
- **10초 앞/뒤로 이동**: 컨트롤 바의 `◀ 10s`/`10s ▶` 버튼을 누르면 "▶▶ +10초" 안내와 함께 이동. **재생 중 영상 위를 좌우로 스와이프**하면 아무 UI도 띄우지 않고 조용히 10초 앞/뒤로 이동해 영상만 보임(재생도 멈추지 않음)
- **프레임 단위 끊어보기**: 컨트롤 바의 `|◀`/`▶|` 버튼으로 1프레임씩 이동. 일시정지 중 영상 위를 **좌우로 드래그(터치)** 하면 프레임 스크럽. 실제 프레임 레이트를 재생 중 자동 추정해 정확한 간격으로 이동하며, 일시정지 중에는 현재 프레임 번호도 표시
- **프레임 비교 분석**: 상단 `🔍 비교` 버튼으로 최대 4개(레이아웃 3·4에서 불러온 영상 수만큼)까지 비교. 드롭다운으로 자세히 볼 두 영상(A/B)을 고르고, 3개 이상 불러왔으면 **전체 비교 요약**으로 A 기준 나머지 모두와의 차이 %를 한 번에 확인. **정밀 비교(프레임)**는 같은 시점 픽셀을 직접 대조하고, **느슨한 비교(동작)**는 픽셀이 완전히 같지 않아도 화면 영역별로 실제 움직이는 정도(모션)를 비교해 "동작 자체가 다른 경우"(한쪽만 움직임 등)를 잡아냄. 이동 단위(1f/10f/50f/100f)로 이동 폭 조절, **전체 자동 비교**로 두 방식 모두 영상 전체를 자동으로 훑어 차이나는 구간 리포트(그래프 + 시간대 목록, 탭하면 해당 지점으로 이동) 생성, A/B 개별 1프레임 정렬(오프셋 표시), 민감도 조절, 패널 내 `?` 버튼으로 사용법·용어 상세 설명 제공
- **슬롯별 개별 컨트롤**: 재생/일시정지, 음소거, 배속(0.5x~2x), PiP(화면 속 화면), 전체화면, 영상 교체
- **전체 컨트롤**: 전체재생 / 전체정지 / 전체 음소거
- **모바일 최적화**: `playsinline` 인라인 재생, 터치 탐색, 세이프 에어리어(노치) 대응

## 아이폰(파일 앱)에서 사용하기

1. `index.html`을 아이폰의 **파일(Files) 앱**에 저장합니다.
   - AirDrop, iCloud Drive, 메일 첨부, 카카오톡/메신저 다운로드 등 어떤 방법이든 가능
2. 파일 앱에서 `index.html`을 탭하거나, Safari 주소창에 공유하여 엽니다.
   - 파일 앱 미리보기로 열리는 경우: 공유 버튼 → **Safari로 열기**
3. 각 슬롯의 **영상 선택** 버튼을 탭하면 iOS 선택창이 뜨고, **파일 앱(둘러보기)** 또는 사진 보관함에서 영상을 고를 수 있습니다.
   - 파일 대신 **주소(URL)로 재생**하려면 빈 슬롯의 "또는 URL로 재생"을, 이미 영상이 있는 슬롯은 우측 상단의 링크 아이콘을 눌러 mp4·m3u8 등 직접 재생 가능한 영상 파일 주소를 입력하세요. 유튜브 등 일반 웹페이지 링크는 지원되지 않습니다.
4. 영상을 불러온 뒤에는 중앙의 재생 버튼을 직접 눌러 재생을 시작하세요. 여러 슬롯을 연속으로 채울 때도 각 슬롯을 탭해서 재생하면 iOS의 자동재생 제스처 제한 없이 모두 안정적으로 재생됩니다.
5. 파일로 불러온 영상은 기기에서 직접 재생되며(로컬 Blob) 어디에도 업로드되지 않습니다. URL로 불러온 영상은 해당 URL 서버로 직접 스트리밍 요청이 나갑니다(이 앱을 거치지 않는 일반적인 `<video>` 재생과 동일).

> **동시 재생과 소리에 대해**: iOS/Safari는 소리가 있는 영상을 여러 개 동시에 재생하는 것을 지원하지 않아, 새 영상을 재생하면 이전에 재생 중이던(음소거 안 된) 영상이 자동으로 일시정지됩니다. 이를 피하기 위해 모든 영상은 기본적으로 **음소거 상태로 로드**됩니다 — 화면(그림)은 여러 개가 동시에 재생되고, 소리가 필요한 슬롯만 해당 슬롯의 음소거 버튼으로 개별 해제해서 사용하세요.
>
> 참고: 동시 재생 가능한 영상 개수는 기기의 하드웨어 비디오 디코더 성능에도 영향을 받습니다. 구형 기기에서 3~4개 고화질 영상을 동시에 재생하면 버벅일 수 있습니다.

## 프레임 비교 분석 사용법

같은 영상의 여러 버전(예: 원본 vs 인코딩본, 수정 전/후, 여러 후보안)을 대조할 때 사용합니다. 패널을 열면 상단에 `?` 버튼이 있어 아래 내용을 앱 안에서도 바로 확인할 수 있습니다.

1. 레이아웃을 2 이상(최대 4)으로 하고 비교할 영상들을 슬롯에 불러옵니다.
2. 상단 `🔍 비교`를 누르면 불러온 영상이 모두 같은 시점으로 맞춰지고 비교 패널이 열립니다.
3. **비교 대상 A/B** 드롭다운에서 자세히 볼 두 영상을 고릅니다. 3~4개를 불러왔다면 아래 **전체 비교 요약** 버튼으로 A 기준 나머지 모든 영상과의 전체 차이 %를 한 번에 확인해, 가장 다른 영상을 먼저 파악한 뒤 그 조합을 A/B로 선택할 수 있습니다(요약은 속도를 위해 항상 정밀 방식으로 계산됩니다).
4. 비교 방식을 고릅니다.
   - **정밀 비교 (프레임)**: 같은 시점 두 프레임을 픽셀 단위로 직접 대조합니다. **차이 강조** 모드에서 다른 픽셀이 핑크로 표시되고, "전체 차이 픽셀 %"와 "차이가 큰 부분: 가로94%·세로6% 12.3%" 형식의 위치 분석이 나옵니다. 화면을 가로·세로 각 9칸(총 81개 구역)으로 세분화해 어디가 다른지 꽤 정밀한 위치까지 짚어줍니다. 완전히 동일한 영상의 미세한 차이까지 잡아내지만, 화질·인코딩이 조금만 달라도 다르다고 나올 수 있습니다.
   - **느슨한 비교 (동작)**: 픽셀 색상이 아니라 화면 영역별로 실제 움직이는 정도(현재 지점부터 약 10프레임의 밝기 변화량)를 비교합니다. 화질·노출 차이에는 둔감하고, "동작 차이 점수"(0~100, 클수록 동작 패턴이 다름)와 "차이가 큰 부분", 특히 한쪽만 움직이고 다른 쪽은 정지해 있으면 "(A만 움직임)" 같은 표시로 알려줍니다.
5. **이동 단위**(1f/10f/50f/100f)를 고른 뒤 `−□f`/`+□f`로 그 폭만큼, `|◀ 1f`/`1f ▶|`로 항상 정확히 1프레임씩(또는 화면 좌우 드래그, ←/→ 키) 불러온 모든 영상을 함께 이동하며 확인합니다. 긴 영상은 50f·100f로 빠르게 훑고, 세밀하게 볼 땐 1f를 쓰세요.
6. 수동으로 넘겨보지 않고 **영상 전체를 한 번에 훑고 싶다면 `▶ 전체 자동 비교`**를 누르세요. 현재 A/B 두 영상을, 현재 선택된 방식(정밀/느슨) 그대로 처음부터 끝까지 이동 단위 간격으로 자동 스캔한 뒤, 시간대별 차이 그래프와 "0:12(360f) ~ 0:18(540f) · 평균 8.4% · 최대 12.1%" 형식의 차이 구간 목록을 보여줍니다. 목록의 구간을 탭하면 그 지점으로 바로 이동해 위쪽 상세 화면으로 확인할 수 있습니다. 스캔 중 버튼을 다시 누르면 중지됩니다. (느슨한 비교의 자동 스캔은 지점마다 별도로 훑기 때문에 정밀 비교보다 훨씬 오래 걸리므로, 긴 영상은 이동 단위를 50f·100f로 크게 잡는 것을 권장합니다.)
7. 현재 A/B의 시작점이 어긋나 있으면 **정렬** 줄의 `A ±1f`/`B ±1f`로 한쪽만 이동시켜 맞춥니다(현재 오프셋이 프레임 수로 표시됨).
8. 미세한 차이가 전체에 깔려 판단이 어려우면 **민감도**(느슨한 비교에서는 **움직임 민감도**)를 조절해 실제로 달라진 부분만 보이게 하세요.

> URL로 불러온 영상은 해당 서버가 CORS를 허용해야 정밀·느슨·전체 비교 요약·전체 자동 비교 모두 분석이 가능합니다(브라우저 보안 정책). 파일 앱에서 불러온 영상은 제한 없이 비교할 수 있습니다.

## 지원 포맷

브라우저(iOS는 Safari 기준)가 재생 가능한 포맷을 그대로 따릅니다: MP4(H.264/HEVC), MOV, M4V, WebM(데스크톱) 등.
